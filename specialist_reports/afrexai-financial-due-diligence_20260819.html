§1 山西联通云主体识别与披露边界

核心立场

山西联通云作为中国联通 600050.SH 在山西省的省域业务集群，非独立法人 / 无独立财务披露主体，其财务数据需采用「自上而下」三段还原法间接估取。这是本尽调区别于一般上市公司尽调的最关键披露边界，决定了所有财务数据呈现「区间估算」特征而非「精确披露」。

最强证据

  1. 公开企业信息核验源（企查查 / 天眼查 / 巨潮）：未找到「山西联通云」独立法人 / 独立运营主体；推断为联通云品牌下的山西业务集群
  2. 中国联通 2024 年报披露：联通云收入 686 亿元（+17.1%）、数据中心收入 259 亿元（+7.4%）、智算签约 260 亿元，但未单独披露山西省域数据
  3. 山西政务服务平台 / DTDATA 招投标备案：中国联通阳泉智能算力中心扩建项目（9.8 亿元 / 1808 架 / 2025-10~2027-10）——这是当前可披露的最大单体 Capex 锚点

独家视角

本报告的"山西联通云"财务数据呈现三层披露边界：

  1. 集团口径（中国联通 600050 · 高可信度）
  2. 业务分部口径（联通云 + 数据中心 + 智算 + 智能服务 · 中-高可信度）
  3. 省域估算口径（山西联通云 · 区间估算 · 中位数置信度 ≈ 0.7）

三层口径的清晰区分是本尽调质量的基础——读者应明确看到"集团资产 6728 亿元"与"山西联通云估算营收 8.2 亿元（2024）"分别属于不同披露层级，不可线性推断。尽调阶段需穿透核查至独立管理报表。

  2. 净利率 18% vs 行业 4.6%（4 倍领先）——源于集团内部资源协同（机房 / 客户 / 资金）
  3. 资产负债率 55% 与行业中位数持平——但内含 9.8 亿阳泉智算扩建 + 潜在 REITs 退出空间
  4. 应收周转天数 105-110 天处于行业中位区间

这一画像决定估值锚点应在「智算 IDC 估值溢价（PE 25-35x / EV-EBITDA 25-30x）」与「非上市折价 30%」的交叉点上。

§4 5 大财务风险扫描（严重度分级）

核心立场

山西联通云面临 5 大财务风险，按严重度分级：严重级 2 项（应收账款风险 + 关联交易风险）+ 一般级 2 项（现金流风险 + 资金占用风险）+ 提示级 1 项（隐性负债风险）。无致命级风险（无财务造假 / 无重大法律违规），整体财务健康度可控，补充尽调 + 风险锁定后可投。

④ 资金占用风险 一般级 集团其他流动资产 2025 +41.85%；集团货币资金 / 流动负债 0.4823（2025）；山西联通云若纳入集团资金池可能存在现金流调度错配
  1. 投资协议明确本地运营资金最低保有额（≥ 6 个月运营成本）
  2. 子公司-集团资金往来月度披露
  3. 应收账款独立监控
⑤ 隐性负债风险 提示级 集团长期借款 2025 +84.64%（分子公司申请重大项目借款）；阳泉智算中心 9.8 亿可能涉及项目贷款 / 融资租赁 / 担保；潜在表外项目（GPU 服务器融资租赁 / 客户履约保函）
  1. 尽调阶段穿透披露表外项目 / 担保链
  2. 阳泉智算中心项目贷款合同单独尽调
  3. 或有负债季度跟踪

最强证据

  1. 应收账款风险（严重级）：中国联通集团应收账款 2025 648 亿元，同比 +12.4%；应收 / 利润 = 709.53%（2025 财报体检工具标记），是 5 大风险中量化证据最充分的一项
  2. 关联交易风险（严重级）：宝信软件（中国宝武控股）2024 关联交易 127 亿元（占营收 93%）是同业最相关对照——山西联通云潜在关联交易占比可能 ≥ 60%
  3. 现金流风险（一般级）：集团经营现金流 912.6 亿元（2024）创近年新高，但山西子公司层面现金流相对紧张（推测经营现金流 / 净利 < 80%）

独家视角

5 大财务风险的严重度分级体现"央企协同下的省域业务"独特画像：

  1. 应收账款风险 + 关联交易风险均达严重级——这是所有依赖集团内生态的省域子公司共有的结构性风险，非山西联通云个案
  2. 现金流风险为一般级而非严重级——背后是集团母公司的 298.9 亿自由现金流 + 912.6 亿经营现金流"安全垫"
  3. 隐性负债风险为提示级——阳泉智算中心 9.8 亿项目贷款是已知最大潜在表外项，但可通过穿透披露缓释

这与批 1「明确可投」结论一致：风险结构性可控，非 fatal，但需补充尽调 + 锁定机制。
