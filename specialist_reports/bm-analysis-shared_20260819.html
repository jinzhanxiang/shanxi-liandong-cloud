§1 模式定位与一句话核心判断

核心立场

山西联通云是中国联通集团旗下"省域级 AIDC + 联通云 + 智算一体化"双主业平台型重资产运营商，其商业模式本质是「重资产 CapEx 投入 + 长期客户合约 + 算力规模效应 + 央企集团信用背书」四元叠加的「章鱼型国资云算服务商」；以阳泉云峰智算中心（300 个 12kW 机柜，PUE≤1.15，80% 绿电）为山西省域核心节点，向上承接中国联通集团"东数西算"枢纽和"45 EFLOPS 智算规模 / 115 万标准机架"国家级算力网络，向下服务山西省"6.57 万标准机架 / 32 EFLOPS"全省算力底座。

最强证据

  1. 阳泉智算中心落地：山西云峰大数据智能算力产业园核心区已安装 280 个 10kW 机柜；中国联通阳泉智算中心一期 300 个 12kW 机柜 / 256 台 GPU 服务器 / 背板式液冷 / PUE≤1.15 / 80% 绿电 / 总投资额披露。 [公开 AI 搜索 · 阳泉市政府门户网站 2026-07-14 + 山西网信网 2026-07-15 + 山西晚报]
  2. 中国联通集团算力规模：2025 年 IDC 收入 281 亿元（同比 +8.5%）· 标准机架 110 万+ · 机柜利用率超 72% · 智算规模 45 EFLOPS · 联通云收入同比 +5.2% · 服务近 40 万企业客户。 [公开 AI 搜索 · 中国联通 2025 年报 + 长江证券 2026-03-26 + 长城证券 2026-03-23 + 兴业证券 2025-08-25 + 第一上海证券 2026-03-24 · 5 家独立券商研报交叉验证]
  3. 山西省域算力底座：山西全省在用数据中心 47 个 / 在用机架 6.57 万标准机架 / 智算规模 32 EFLOPS / 综合算力指数全国第 8（能效水平全国第 5）。 [公开 AI 搜索 · 山西省通信管理局 2025-09-30 · 山西省《2025 综合算力指数》披露]
  4. 联通云山西产品矩阵：已形成「通算 → 智算 → 超算」全栈算力服务体系，从太原到大同算力网络全域覆盖；2025 年云峰智算中心、大同御东数据中心智算机房建设项目（外电引入监理）已招标落地。 [公开 AI 搜索 · 新华网 2026-08-18 + 中国联通山西省分公司国企开放日 + 山西建设工程招标网 2025-10-23]

独家视角

山西联通云 ≠ 中国联通云 ≠ 中国联通 IDC 业务：三层嵌套但口径不同。主公强调的「区分机构间 REITs vs 公募 REITs / 区分普算 IDC vs 智算 IDC」对应到本项目上是：「山西联通云属于中国联通集团旗下山西省域分公司业务 → 不存在独立 IPO / 公募 REITs 路径 → 只能走"母公司（联通数科/联通集团）增持 / 集团内换股 / 集团内资产重组 / 机构间 REITs（资产打包上市）"四条路径；山西省域业务"普算 IDC（已建成御东、太原等老节点）+ 智算 IDC（阳泉云峰等新节点）"两段并存 → 普算段现金流稳定但增速低、智算段增长快但客户验证周期长 → 退出估值锚需双段折现后再加权」。

§6 STORM 多视角辩论（≥ 3 视角 · 核心立场 + 最强证据 + 综合裁决）

6.1 模式乐观派 · 核心立场

立场：山西联通云商业模式可扩张性强，是 AI 时代"东数西算" + 央企国资云 + 智算一体化三大趋势的"最大交集"。

最强证据：

  1. 中国联通集团整体算力收入快速放量（2026H1 算力收入 419 亿同比 +13%，智算中心 +11%），AI 收入同比 +140% 持续高增
  2. 山西省域综合算力指数全国第 8，能效水平全国第 5，山西省国资委明确"算力设备制造—算力基础设施—算力服务和融合应用"产业生态战略
  3. 阳泉智算中心一期 300 个 12kW 机柜落地只是开始，山西云峰智算中心总投资 20 亿元，总承载 1 万 P 智能算力，A2/B1 等数据中心楼宇及柴油发电楼均已完成基础设施

6.2 落地怀疑派 · 核心立场

立场：商业模式落地存多重障碍 —— 山西联通云作为非独立法人 / 无独立财务 / 无独立客户合同 → 退出路径极度受限（独立 IPO / 老股转让完全不适用）；智算 IDC 上架率虽然集团口径 74% 优秀，但阳泉新节点的 12kW 高密度机柜实际客户落地进度未充分披露。

最强证据：

  1. 2026H1 净利润 41.39 亿元同比下降 34.8%，主因增值税 + 人工成本投入节奏 → 利润端短期承压
  2. 智算 IDC 客户验证周期长（从签约到 GPU 服务器到位 + 调测 + 业务上线通常 12-18 个月），新机柜爬坡期收入贡献慢
  3. "机构间 REITs / 公募 REITs" 路径需要剥离独立法人和独立资产 → 联通集团内重组复杂度高、周期 2-3 年 + 监管不确定性

6.3 竞对对比派 · 核心立场

立场：与同行业可比公司商业模式对比，山西联通云有央企国资 + 阳泉区位双重稀缺性，但规模显著小于头部第三方 IDC（润泽科技 / 光环新网），需靠"央企云+区域中心"差异化路径突围，而非规模比拼。

最强证据：

  1. 润泽科技 2024 年 IDC 业务前 5 大客户合计 16.4 亿元（占比 96.4%），客户集中度极高；中国联通整体政企客户结构分散（前 5 大客户占比小）→ 联通云客户结构更稳健
  2. 奥飞数据 2026 年可比公司 Wind 一致预期 EV/EBITDA 均值 20 倍 → 央企国资重估溢价可上修至 22-25 倍
  3. 中国移动（同期可比）2026H1 智算总规模达 112700 PFLOPS + AIDC 收入同比 +486.1%，规模效应更显著；中国联通需通过"差异化定位 + AI 云 + Token Plan"突围

6.4 综合裁决

裁决：山西联通云商业模式可行性高，但退出路径选择是核心变量。综合三派最强证据权衡 —— 资产质量和现金流可预测性 4.92/5.0 优秀（乐观派占优）· 退出路径明确度因"独立法人缺失"略低（怀疑派占优）· 规模对比非头部（对比派占优但差异化定位可缓冲）。

建议下钻方向：

  1. 下钻联通集团内资本运作框架（如联通数科独立运营进展 / 联通集团混改深化 / 国调基金二期入股）
  2. 下钻机构间 REITs 路径（参照润泽科技公募 REIT 已发行 45 亿规模 + 扩募 75.77 亿 + 万国数据 ABS 探路 + REITs 落地组合 → 山西联通云可参照路径）
  3. 下钻山西省国资委 + 山西联航投资 → 联通集团 → 中国联通 → 联通数科多层股权链条的资本运作空间
  4. 下钻阳泉智算中心二期 + 大同御东 + 太原 IDC 后续扩产计划
