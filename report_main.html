§1 项目概述

核心立场

山西联通云是中国联通集团旗下山西省域级 AIDC + 联通云 + 智算一体化算力服务运营商，依托集团算网底座（45 EFLOPS 智算 + 115 万标准机架）服务山西能源/煤炭/医疗/政务/制造 6 大客户群，资产质量 5.0/5.0、退出路径明确度 4.5/5.0、综合评分 4.67-4.92/5.00，建议投资规模 100-200 亿元、目标 IRR 18.5%。

最强证据

  1. 中国联通 2024 联通云收入 686 亿元（+17.1%）/ 数据中心收入 259 亿元（+7.4%）/ 智算签约 260 亿元 —— 集团赋能强势（数据来源：market-analysis_20260819 §3 中国联通集团财务 + bm-analysis-shared_20260819 §六 6 维证据）
  2. 山西联通智能算力规模 363 PFLOPS / 平均利用率 67% / PUE 1.18 —— 山西 32 EFLOPS 全省智算规模中占比超 30%（数据来源：market-analysis_20260819 §4.2 山西联通云业务）
  3. 阳泉智算中心一期 300 个 12kW 机柜 + 80% 绿电 + PUE 1.15 + 9.8 亿元扩建 1808 架（2025-10~2027-10）—— 单体 Capex 锚点明确（数据来源：afrexai-financial-due-diligence_20260819 §1.3 山西联通阳泉智算中心 + bm-analysis-shared_20260819 key_data_points 阳泉云峰智算中心）
  4. 山西综合算力指数全国第 8 / 能效水平全国第 5 / 城区内算力中心间 ≤ 1ms 时延 / 到京津冀 5ms —— 区位稀缺不可复制（数据来源：market-analysis_20260819 §4.2 山西区位 + bm-analysis-shared_20260819 §六 regional_resources 4.5 星）

独家视角

山西联通云的核心稀缺性不在 IDC 资产本身（同行可比），而在「央企国资 + 东数西算八大枢纽 + 京津冀 5ms 时延 + 联通集团 45 EFLOPS 算网底座」四维护城河组合 —— 该组合在山西区域内不可复制：东数西算八大枢纽仅 8 个，山西省占其一；央企国资信用使民营 IDC 资本成本差距 200-300bp；联通集团 2026 资本开支 500 亿 + 算力占比 37% 提供集团赋能底盘。「属地国资云 + 央企集团赋能 + 算网融合」三位一体决定本项目在退出路径上拥有 5 条中 3 条高适用（机构间 REITs 4.8 星 + 母公司增持 4.5 星 + 央企换股 3.5 星），这是普通第三方 IDC 无法企及的退出选项丰富度。

§2 业务结构

核心立场

山西联通云业务呈现「主业平台型（联通云 + IDC）+ 衍生型（Token Plan + 5G 专网 + 智算一体机）+ 创建型（联通星罗 + 元景 MaaS）」三型叠加的章鱼型业务结构，2024 中位数估算营收 8.2 亿元，主营业务为 AIDC（智算 IDC）+ 联通云山西区域交付 + 山西政务云/医疗云/煤炭工业互联网智算平台三大平台业务。

最强证据

  3. 晋云山西煤炭工业互联网智算平台（64P AI 算力）
  4. 山西省医疗数字影像云平台（383 所二级以上公立医院）
  5. ③ 山西省政务云平台（传染病监测、应急指挥）—— 三大平台业务锚定（数据来源：market-analysis_20260819 §4.2 山西联通云业务 + afrexai-financial-due-diligence_20260819 §1.1 山西关键业务）

独家视角

山西联通云的「平台业务」组合具有「属地国资锁定 + 集团品牌赋能 + 央企资本信用」三重属性 —— 山西省政务云、煤炭工业互联网智算平台、医疗数字影像云三大平台一旦签约即被属地政策锁定（5-10 年长单），迁移成本极高（机房搬迁 + 系统集成商资质重建 + 数据安全等保 2.0 重新认证），客户留存率实质接近 100%（机房搬迁成本远超重置成本）。这与润泽科技 2024 年 IDC 业务前 5 大客户合计占比 96.4% 形成鲜明对比 —— 央企国资背景的「平台业务」客户结构分散但单客户体量大、抗周期性强，是本项目现金流可预测性 5.0/5.0 的真正来源。

§3 财务表现

核心立场

山西联通云作为省域业务品牌无独立财务披露，采用「自上而下」三段还原法估算：2024 中位数营收 8.2 亿元 / 2025e 10.4 亿元 / EBITDA 率 50% / 归母净利率 18% / ROE 8.5% / 应收账款周转天数 105 天，净利率显著优于同行 4 倍（行业中位数 4.6%）但应收账款风险与同行可比。

最强证据

  1. 中国联通集团 2024 营业收入 3895.89 亿元 / 归母净利 90.29 亿元 / 净利率 5.29% / 毛利率 23.54%（2025）/ ROE 1.25%（2026Q1）—— 集团财务基础（数据来源：afrexai-financial-due-diligence_20260819 §2.1 中国联通合并报表）
  2. 山西联通云 2024-2025 估算：营收 8.2 亿（中位）/ 10.4 亿 / EBITDA 4.1 亿 / 5.2 亿 / 归母净利 1.48 亿 / 1.87 亿 —— 中位数情景（数据来源：afrexai-financial-due-diligence_20260819 §3.2 + financial-analyst_20260819 §3.1 山西联通云财务三表情景）
  3. 山西联通云财务指标对比同行：净利率 18% vs 行业中位数 4.6%（优 13pp）/ ROE 8.5% vs 行业 4%（优 4.5pp）/ 资产负债率 55% vs 行业 55%（持平）—— 同业可比（数据来源：afrexai-financial-due-diligence_20260819 §4 同行对比 2024）
  4. 中国联通集团应收账款 2022-2025 从 280 亿 → 648 亿（4 年 +131%）/ 应收账款/营收比 7.2% → 16.5% / 周转天数 27 天 → 54 天 —— 集团口径应收上行（数据来源：afrexai-financial-due-diligence_20260819 §4.1 应收账款风险）

独家视角

山西联通云财务表现的核心矛盾是「高利润率（净利率 18% 优同行 4 倍）+ 高应收占比（应收/营收 16.5% 集团口径）」—— 这种矛盾在「央企国资重资产 + 政企长单 + 政企回款节奏」的业务结构下有合理解释：政企长单确认收入时点早于回款时点（12-24 个月账期），形成「利润已实现、现金未到位」的会计-时间差，而非「应收账款减值」的真实风险 —— 这一点与宝信软件 2024 关联交易 127 亿（占营收 93%）的同业对照形成印证（央企国资云标的均呈现类似特征）。QoE 调整后净利率 12-15% 是审慎假设下的合理区间。

核心立场

山西联通云作为中国联通集团旗下省域业务品牌，无独立资本运作史；可参照的关键资本动作包括

③ 联通集团 2026 资本开支 500 亿元 / 算力占比 37% + 国调基金等央企股东背书。

最强证据

§5 公司治理

核心立场

山西联通云为多层叠加结构（联通集团 100% 国务院国资委 → 联通集团 → 中国联通 35.8% → 联通运营公司 → 联通数科 100% → 山西三主体），治理特征 = 「央企国资 + 多层股权穿透 + 关基属性 + 关联交易占比较高」，合规性强但退出灵活性受集团内重组复杂度制约。

最强证据

  2. 联通集团最终实控人 = 国务院国资委（通过联通集团 100% 间接控制中国联通 35.8% 股份）—— 国资委最终持股（数据来源：legal-due-diligence-checklist_20260819 §2.1 国务院国资委 + 联通集团 35.8% 中国联通）

  4. 中国联合网络通信有限公司山西省分公司（基础电信运营 + 智算项目签约主体）
  5. 联通云数据有限公司山西分公司（云业务省级落地）
  6. ③ 联通数字科技有限公司山西省分公司（数字化解决方案省级落地）—— 三层叠加并存（数据来源：legal-due-diligence-checklist_20260819 §2.6 山西三主体）
